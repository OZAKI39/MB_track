PNG is suitable for direct insertion; PDF/SVG are vector variants where available; MP4 files are animations. All existing English/Arial rendering is preserved. Data and provenance accompany the assets. Shared inputs are stored once under shared_data/. The raw video remains in the project data directory.

inventory.csv records original paths, collected paths, sizes and SHA-256. collection.json records selected versions and verification. Earlier revisions, incomplete renders, debug screenshots, duplicate ZIPs, environments and weights are excluded. No standalone Slide 5 or Slide 7 assets were generated in the preceding requests, so those slide folders are not invented. Baseline results are grouped by topic without assigning a slide number.

This copy verification is not a new scientific accuracy test. PowerPoint playback was not tested during collection.
